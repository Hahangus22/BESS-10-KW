 AMETHYST  Series  AT  Command  Manual  v1.1   3.  Nested  object  Membuat  hirarki  object  bertingkat  menggunakan  “/“  sebagai  pemisah.   AT+INSERTDATA=sensor/indoor/temperature,25.5  
 {    "sensor":  {      "indoor":  {        "temperature":  25.5      }    }  }  
 4.  Object  dalam  array  Menggunakan  “[N]“  untuk  menulis  ke  slot  index  tertentu  dalam  array  secara  bertahap.   AT+INSERTDATA=inverter/[0]/voltage,220  AT+INSERTDATA=inverter/[0]/current,5  AT+INSERTDATA=inverter/[1]/voltage,215  
 {    "inverter":  [      {        "voltage":  220,        "current":  5      },      {        "voltage":  215      }    ]  }  
 5.  Array  dalam  array  index  Menyimpan  multiple  value  ke  dalam  object  yang  berada  di  slot  array  tertentu.   AT+INSERTDATA=inverter/[0]/phases,220,221,219  
 {    "inverter":  [      {        "phases":  [  220,  221,  219  ]      }    ]  }
